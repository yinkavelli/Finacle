# Finacle

Finacle is a premium personal finance and budgeting app prototype focused on calm money clarity. It includes a polished marketing hero, an interactive mobile preview, light/dark theming, and three core finance screens:

- **Home** — net cash, accounts, monthly budget progress, and recent activity.
- **Insights** — spending trends, category allocation, and top merchants.
- **Activity** — searchable transaction ledger with filters and weekly summary metrics.

## Run locally

```bash
npm run dev
```

Open <http://localhost:5173> to view the prototype.

## Build

```bash
npm run build
```

The static production files are copied into `dist/`.
